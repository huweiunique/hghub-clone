# CF 优选 IP

优选只影响 App 到已配置后端的连接。后端必须是接入 Cloudflare 的 HTTPS 域名；
服务器 IP 加端口不能通过填写 CF IP 直接加速。视频 CDN 按原播放方式连接，不受此项控制。

## iPhone / iPad

安装包含此功能的新 App 后，在“我的 → 设置”中开启优选：

- 关闭：使用系统普通连接。
- 开启：从 `cf.090227.xyz` 获取所选运营商的候选列表，再与自定义 IP 合并测速。
  默认使用电信列表，不检测手机运营商，不直接采用第三方列表的第一项。
- 自定义候选 IP：可填多条 IPv4 / IPv6，每行一个，也支持逗号或空格分隔。
  不含 `http://`、`https://`、端口或路径。可以删除输入框内的地址后重新保存。
  自动列表和自定义地址按实际地址字节去重，IPv6 的不同写法也只测试一次，保留来源标识。

点“保存并测速择优”保存候选配置，并测试合并后的所有候选。
配置及上次选择保存在当前设备，按后端域名和端口分别保存。
“重新测速并选择”使用当前已保存的候选；自动列表过期或尚未获取时先重新拉取。
“更新列表并测速”强制获取第三方最新列表，然后与自定义 IP 一起测试。
第三方不可用时继续使用已有缓存和自定义候选，明确提示，不丢弃自定义候选。

每个 IP 通过两次独立、禁止回退的 HTTPS 连接访问同一后端 `/health`，要求系统证书校验成功、
HTTP 200、无重定向。只有两次都成功的地址参与选择，按两次平均耗时取最低者。
每轮最多同时测三个地址，每次请求资源超时十秒；去重后最多 128 个候选，超限明确提示，
不会静默省略一部分候选。相同平均耗时保持候选顺序。

界面显示已完成数、每项来源、平均耗时或失败原因，并按耗时排序标记选择。
显示的耗时包含建连、TLS 和健康接口响应，不是 ICMP ping，也不是下载速度，
不代表视频 CDN 的速度。全部失败会清空选择并使用普通连接。
“停止测速”取消未完成请求，不从本轮部分结果中选 IP，仍在候选池中的上次选择会保留。

测速完成后用于后续新连接，已有连接可能继续复用；需要完全切换时重新打开 App。
启动直接使用上次测速选出的 IP，不在首屏批量测速；第一次尚无结果时使用普通连接，
进入设置后主动测速。换 Wi-Fi、切蜂窝或发现变慢时，重新测速更新选择。

iOS 17 及以上、且后端为 HTTPS 域名时显示此能力。
iOS 16 等不支持的环境直接隐藏整块优选区域，包括说明、配置及按钮，使用普通连接。
系统能力由 App 单独提供；支持的设备若读取原生设置失败，会显示错误和“重试读取优选设置”，
不会把通信错误当作系统不支持而隐藏入口。默认 HTTPS/HTTP 端口在原生桥来源检查中统一归一化，
其他协议、域名、非匹配端口及子框架仍拒绝访问。随包脚本可覆盖旧服务端脚本，修复无需先更新后端。
设置入口脚本随 IPA 分发，旧后端不需要部署 `local_ext/` 也能使用此功能。

## 连接与回退

App 内部使用只监听 `127.0.0.1` 的 HTTP CONNECT 通道，仅允许当前后端域名及端口。
连接目标是优选 IP，隧道中的 TLS 仍由 WebKit 或 URLSession 按原域名完成，
保留 Host、SNI、Cookie 和系统证书校验；不修改系统代理、不安装证书、不解密 HTTPS。

优选 IP 无法建立 TCP 连接时，该连接尝试普通域名解析并回退，设置中显示回退状态。
首屏优选连接出现 TLS 或其他导航错误时，关闭当前通道并重试一次普通连接。
已建立连接之后的断开和子资源错误仍由 WebView 处理，不能保证每个失败请求自动重放。
测试通道禁止回退，避免普通连接成功被误认为自定义 IP 可用。

## 网页与 Android

网页按钮统一称为“刷新自动列表”，显示处理中、完成和失败状态，强制刷新绕过
服务端缓存。普通浏览器不能通过网页脚本改变 HTTPS 的目标 IP，获取列表不代表已使用。
Android 保留原有的原生优选连接实现；本次自定义 IP 能力面向 iOS，不扩展 Android 原生设置。

## 验证范围

`python tests/run_all.py` 覆盖离线网页事件、列表缓存和接口回执等回归。
`python tests/test_prefip_transport.py -v` 在 macOS 上编译实际 Swift 通道，验证字节转发、
半关闭、域名/端口限制和失败回退；Windows/Linux 明确跳过。
`python tests/test_prefip_ranking.py -v` 在 macOS 上编译实际原生控制器，注入可控网络回执，
覆盖候选去重、并发上限、双次平均耗时择优、全部失败、源不可用、自定义输入错误及取消。
这两类原生测试在 Windows/Linux 明确跳过；IPA 的 macOS 构建流程先执行它们，再用 iOS SDK 编译整个 App。

当前 Windows 环境不能运行 Xcode。iOS 编译及以下真机验收仍需单独完成：
自动列表与多条自定义 IPv4/IPv6 混测、错误 IP、证书错误、停止测速、开关切换、
重启保留、换后端配置隔离、不支持系统隐藏，
以及视频播放和切回普通连接。离线网页测试使用原生桥的可控回执，不代替这些验收。
